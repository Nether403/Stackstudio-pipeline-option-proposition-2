## Upgrading to the Latest Version

Follow these steps to upgrade StackStudio seamlessly. Backup your configurations first to avoid data loss.

<Steps>
  <Step title="Backup Configurations" icon="database">
    Export your pipelines and settings.

    ```
    stackstudio export --output=backup.yaml
    ```
  </Step>

  <Step title="Update Package" icon="download">
    Choose your package manager.

    <CodeGroup tabs="npm,yarn">
    ````bash
    npm install stackstudio@latest
    ````

    ````bash
    yarn add stackstudio@latest
    ````
    </CodeGroup>
  </Step>

  <Step title="Run Migrations" icon="settings">
    Apply any required schema updates.

    <Tabs>
      <Tab title="Node.js" icon="nodejs">
      ````javascript
      const StackStudio = require('stackstudio');
      await StackStudio.migrate({ version: '1.3.0' });
      ````
      </Tab>
      <Tab title="Python" icon="python">
      ````python
      from stackstudio import StackStudio
      stackstudio = StackStudio()
      stackstudio.migrate(version='1.3.0')
      ````
      </Tab>
    </Tabs>
  </Step>

  <Step title="Verify Installation" icon="check-circle">
    Test a sample pipeline.

    ```yaml
    pipelines:
      - name: test-pipeline
        steps:
          - run: echo "StackStudio v1.3.0"
    ```
  </Step>
</Steps>

<Expandable title="Migration Notes for v1.1.0 Breaking Changes" default-open="false">
If upgrading from v1.0.x, update your YAML configs from the old JSON format:

**Old (deprecated):**
```json
{"pipeline": {"name": "legacy"}}
```

**New:**
```yaml
pipeline:
  name: modern-pipeline
```

Run the migration script once:

````bash
stackstudio migrate-legacy --input=old-config.json --output=new-config.yaml
````
</Expandable>
